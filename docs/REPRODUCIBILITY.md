# Reproducibility

## 1. Environment

CPython 3.12 with the exact pins in `requirements.txt` (the reported run used CPython 3.12.3 on
Linux x86-64, two CPU cores). Indigo and Open Babel are needed only for `scripts/14_crosstoolkit.py`.

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

All paths can be overridden with environment variables: `MOLECULEACE_DIR` (upstream checkout,
default `external/MoleculeACE`), `MSA_OUT` (analysis tables and cache, default `outputs/`),
`MSA_PRED` (prediction directory, default = `MSA_OUT`), `MSA_FIGDIR`, `MSA_FIGDATA`.

## 2. Quick verification (tested)

`python reproduce.py all-quick` was run from a fresh copy of this repository in a new virtual
environment created from `requirements.txt`. It clones the audited MoleculeACE commit, redraws the
figures from the released tables, runs the fidelity gate, recomputes the analysis cache, labels and
splits from the upstream files, recomputes the primary statistics from the released predictions, and
compares every regenerated file with the released copy. Expected final line: `verify: OK`.

## 4. Known reproduction limits

1. **Cliff labels** reproduce the shipped `cliff_mol` column exactly in 27 of 30 datasets (median
   100.000%, minimum 99.824%); the residual (1–3 compounds in three datasets) is attributed to RDKit
   version drift.
2. **The shipped split** is reproduced exactly in 19 of 30 datasets when the upstream procedure is
   stratified on the shipped labels (18 of 30 on the recomputed D0 labels); spectral clustering is not
   bit-reproducible across library versions, and no solver option recovers every dataset. The
   primary contrast therefore compares two splits generated by identical code (R0 and R2).
3. **KNN predictions are not reproducible across machines.** MoleculeACE's published KNN
   hyperparameters apply a Euclidean metric to binary fingerprints, so distances are integer Hamming
   distances and 33.4% of test compounds have tied k-th and (k+1)-th neighbors. Predictions differ by
   up to 1.32 log units between scikit-learn neighbor-search backends and between `uint8` and
   `float64` features. Re-running `05_fullrepair.py` will therefore not reproduce the released KNN
   predictions exactly; SVM and GBM reproduced bit-identically across two independently configured
   environments, and RF to within 5.4 × 10⁻⁴ RMSE. `19_knnties.py` quantifies the effect.
4. **The deep-learning models of MoleculeACE were not retrained.**
5. **The matched split control covers SVM only** (RF with the published `n_estimators=1000` costs
   about 215 s per fit on the larger datasets, against 5.5 s for SVM).
6. **The size-capped D3 column** of the label files is produced by section E of
   `18_sensitivity.py` and is therefore not recomputed by `reproduce.py verify`.

## 5. Provenance of the released files

Everything in `labels/`, `splits/`, `predictions/`, `results/summary/` and `figures/` was produced by
the scripts in this repository from the upstream files at the audited commit. `reproduce.py verify`
regenerates labels, splits, split realizations and the primary statistics and checks them against
the released copies byte-for-byte (labels: all recomputed columns, exactly).
